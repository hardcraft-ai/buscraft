# Hardware

KiCad project for the BusCraft adapter: a battery-powered wireless module that plugs straight into an instrument's
IEEE-488 connector. The adapter floats: the instrument's ground never meets the computer's ground.

Every release includes fabrication files ready for upload to a PCB assembly service (Gerbers, drill files, BOM and
component placement), generated from the KiCad project in CI.
