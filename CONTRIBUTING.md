# Contributing

Contributions are welcome: instrument skills, ports to other hardware, fixes, measurement reports.

## Original work only

Everything in this repository must be original work, written by you or by your AI assistant, and released under the
licences in [README.md](README.md#licences). Nothing copyrighted by someone else is added, even in part.

Not allowed in the repository:

- Instrument manuals, programming guides, datasheets, application notes or service manuals, in any form: PDF, scans,
  screenshots, copied text, copied tables or redrawn figures.
- Code, driver files or instrument definitions from vendors, from closed-source tools or from other projects, including
  files converted to another format.
- Logos, product photos or other images that you did not make yourself.
- Measurement data that you did not measure yourself.

Allowed:

- Facts: command names and syntax, response formats, ranges, timings, pin numbers and similar. Facts are not protected
  by copyright, but the way a document presents them is. Learn the fact from the source, then write it down in your
  own words and in this repository's own structure.
- References: name the source (title, document number, edition) and link to it. Do not copy it.
- Make and model names of instruments, only to say which instrument a skill or result is for. No logos, and nothing that
  suggests the maker endorses this project.

If you are unsure whether something may be added, leave it out and ask in the pull request.

## Instrument skills

An instrument skill is written by an AI assistant from what it has learned: the manual it read, the commands it tried
on the instrument and the replies it got. The skill is the result of that work, not a copy of the sources. Each skill
lists:

- the sources it was written from, as references only,
- the hardware and firmware versions it was verified on, and its status: AI draft, verified on hardware, or verified by
  several users.

## Pull request checklist

- [ ] Only original work, nothing copied from manuals, datasheets, vendor code or other projects.
- [ ] Sources listed as references.
- [ ] Verified on hardware, or marked as an AI draft.
